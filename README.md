# Voltex-lib-Injector-

**Made by Voltex**

This APK supports **Quest 1 and up**.

---

## How to Use

### 1. Settings
Change how the lib loads. There are three options:
- **Unity Player Activity** (recommended)
- **Unity Player**
- **Android Manifest** (does not work right now)

### 2. APK Lib
1. Put in your APK.
2. Go to your `libs` folder and add your `lib/*.so` file.
3. Tap **Activate**.
4. You can add more than one lib. Add as many as you want.

### 3. Info Tab
Shows which **Unity version** the APK uses, plus other info about it.

### 4. APK Injector
1. Tap **Continue** to watch what it is doing.
2. When it finishes, you get three buttons:

| Button | What it does |
|---|---|
| **Install** | Asks you to uninstall the game first (if you haven't already). After that, it asks you to install. Once installed, you're done. |
| **Download** | Saves the APK to your device instead of installing it. |
| **Bump +1** | Raises the version code by one, so you don't have to uninstall the game. It just updates the app. |

### 5. App Injector
Same as the APK Injector, but you pick an app from your library. **No APK file needed.**
